# Friends SMP tweaks (server datapack)

Shipped in the pack at `world/datapacks/`, so packwiz installs it into the server's world folder.
(Players' launchers also download it into an unused folder; it does nothing there.)

- **Holly Wreath** (DecorationX: Christmas) is crafted from 8 oak leaves around **sweet berries**.
  Its original recipe (8 oak leaves around red dye) is identical to Macaw's Holidays' Red Oak
  Leaves, so hand-crafting gave whichever recipe the game found first.
